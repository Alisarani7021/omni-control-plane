# اتصال کاوه به کنترل‌پلین (v13 × Omni)

## مدل
نود کاوه یک Worker **هدلس** روی اکانت خودِ تنانت است: API + تونل VLESS + D1 + DO + کرون.
بدون UI و بدون VPS. رابط کاربریِ تنانت **همین ربات/کنترل‌پلین** است و از راه
کانال عامل (`X-Omni-Agent`) با نود حرف می‌زند.

## اجزا
- `src/omni-source.ts` — باندل پین‌شده‌ی کاوه (`scripts/sync-omni-panel.mjs` آن را از
  ریپوی عمومی کاوه می‌گیرد و sha256 را_verify می‌کند؛ هیچ fetch زمان‌اجرا وجود ندارد).
- `src/omni-engine.ts` — ساخت D1 (ایدмпوتنت)، آپلود Worker با بایندینگ‌های
  D1/DO/سکرت‌ها، فعال‌سازی workers.dev، حذف، و کلاینت کانال عامل.
- `src/omni-flows.ts` — فلوهای ربات: ساخت نود + کاربر VIP، لیست کاربران،
  کاربر سریع، بازیابی رمز، حذف نود. کلید عامل مثل توکن اتصال‌ها با AES-GCM و AAD اختصاصی رمز می‌شود.
- `migrations/0005_kaveh_nodes.sql` — جدول نودها.
- دکمه‌ی منو: «⚒️ پنل کاوه» → `v13:omni`.

## مرزها
همه‌ی عملیات داخل همان resource boundary توکن تنانت می‌ماند
(`assertConnectionResourceBoundary` مسیر مشترک است). سکرت‌های نود
(`AGENT_KEY`, `SECRET`) موقع آپلود به‌صورت `secret_text` ست می‌شوند و هرگز به چت تلگرام نمی‌آیند:
ربات فقط لینک اشتراک را (با protect) نشان می‌دهد.
