# کانال عامل (Agent API) — پلی بین کاوه و کنترل‌پلین

## چیست
هفت مسیر تحت `/api/agent/*` که یک orchestrator خارجی (ربات تلگرام v13،
مدیر ناوگان، اسکریپت ops) می‌تواند با آن‌ها یک نمونه‌ی کاوه را بدون UI اداره کند:
ساخت کاربر، خواندن کانفیگ/لینک اشتراک، ریست حجم، حذف کاربر، و برگرداندن پنل
به حالت راه‌اندازی اول («بازیابی رمز»).

## امنیت
- دریچه با سکرت `AGENT_KEY` باز می‌شود (`wrangler secret put AGENT_KEY`).
  بدون آن همه‌ی مسیرها **503** می‌دهند: سطح حمله اصلاً وجود ندارد.
- مقایسه‌ی کلید زمان‑ثابت است و کلید هیچ‌جا لاگ نمی‌شود.
- این نشست مدیر نیست: نوشتن رمز، نوشتن تنظیمات و خروجی پشتیبان ندارد.
- هر عمل تغییردهنده با بازیگر `agent` در گزارش رویدادها ثبت می‌شود.

## مسیرها
| مسیر | کاربرد |
|---|---|
| `GET /api/agent/health` | نسخه، installed، تعداد کاربران |
| `GET /api/agent/users` | فهرست کاربران (q/status/page/size) |
| `POST /api/agent/users` | ساخت کاربر + برگشت `user` و `configs` کامل |
| `GET /api/agent/users/:u` | کاربر + کانفیگ‌ها + لینک اشتراک |
| `POST /api/agent/users/:u/reset` | ریست حجم/درخواست |
| `DELETE /api/agent/users/:u` | حذف کاربر |
| `POST /api/agent/admin/reset` | پاک کردن رمز مدیر → setup دوباره |

همه با هدر `X-Kaveh-Agent: <AGENT_KEY>`.

## نسخه‌ی هدلس (نود تنانت)
`npm run build:headless` یک فایل tunggal می‌سازد:
`dist-headless/kaveh-headless.js` (۷۱KB، sha256 در `dist-headless/SHA256`).
بدون `[assets]` و بدون UI — برای دیپلوی توسط کنترل‌پلین روی اکانت تنانت.
پروفایل دیپلوی‌اش `wrangler.headless.toml` است. کنترل‌پلین هنگام دیپلوی
دو سکرت می‌گذارد: `AGENT_KEY` (کانال خودش) و اختیاری `SECRET`.
